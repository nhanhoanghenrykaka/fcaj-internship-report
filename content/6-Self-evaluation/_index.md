### What I did well

* Used one concrete project to connect AWS services with real requirements.
* Can explain the main Shopsflow flow: CloudFront/S3, ALB → ECS Fargate, RDS, and NAT Gateway for payment calls.
* Started considering security, failure paths, observability, and cost instead of only checking whether the system runs.
* Was willing to revise the original architecture when a component was unnecessary or not sufficiently validated.

### Needs improvement

* Learn Infrastructure as Code with Terraform or AWS CDK.
* Build complete CI/CD from GitHub → ECR → ECS and study deployment strategies/auto scaling.
* Go deeper into Secrets Manager, KMS, WAF, TLS/custom domains, and security hardening.
* Improve monitoring with CloudWatch Dashboards, Alarms, tracing, and clearer pass/fail tests.
* Present technical topics more concisely using problem → solution → architecture → trade-off.

### Conclusion

As of 31/07/2026, I do not consider myself ready to design a complete production AWS system independently. However, I have moved from memorizing service names toward thinking in requirements, request paths, network boundaries, security, failure scenarios, and cost.
