### Những điểm em làm tốt

* Duy trì việc học gắn với một project cụ thể nên các dịch vụ AWS không bị tách rời khỏi bài toán thực tế.
* Có thể giải thích request flow chính của Shopsflow: CloudFront/S3 cho frontend, ALB → ECS Fargate cho API, RDS cho dữ liệu và NAT Gateway cho outbound payment flow.
* Bắt đầu quan tâm tới security, failure path, monitoring và cost thay vì chỉ kiểm tra hệ thống có chạy hay không.
* Sẵn sàng sửa kiến trúc ban đầu khi nhận thấy một thành phần chưa thật sự cần thiết hoặc chưa có đủ bằng chứng thực hành.

### Cần cải thiện

* Học thêm Infrastructure as Code với Terraform hoặc AWS CDK.
* Thực hành CI/CD hoàn chỉnh từ GitHub → ECR → ECS và tìm hiểu deployment strategy/auto scaling.
* Học sâu hơn về Secrets Manager, KMS, WAF, TLS/custom domain và security hardening.
* Cải thiện monitoring với CloudWatch Dashboard, Alarm, tracing và test plan có tiêu chí pass/fail rõ ràng.
* Rèn cách trình bày kỹ thuật ngắn gọn hơn theo problem → solution → architecture → trade-off.

### Kết luận

Đến 31/07/2026, em chưa xem bản thân đã có khả năng thiết kế một hệ thống AWS production hoàn chỉnh. Đây là nền tảng em muốn tiếp tục phát triển sau giai đoạn thực tập hiện tại.
